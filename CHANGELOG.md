# Changelog

Every change to Wayfarer is recorded here: features, fixes, data (each city added or re-ingested), backend, tooling and docs. Newest first. Format based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); sections: **Added**, **Changed**, **Fixed**, **Removed**, **Data**, **Docs**.

How to record a change (enforced in CI by `scripts/check-docs.mjs`):

1. Add a line under **Unreleased** in the same commit as the change — what changed for the user or developer, not how.
2. New or changed feature → also update [README → Features](./README.md#features) (and _Backend reference_ / _Limits and rules_ when relevant).
3. City added or removed → list it under **Data** by name; `docs/CITIES.md` is regenerated by the pipeline.
4. When a milestone or release is cut, rename **Unreleased** to the date / version and start a new one.

### Changed

- Pipeline: sculptures, parliament buildings and promenades are mapped to categories; archaeological ruins are kept (Parthenon); the class-root cache is invalidated when roots change; every HTTP request has a wall-clock deadline (slow WDQS responses hung ingestion). (`c67cdcd`)

### Fixed

- Route optimisation: ORS directions returned 406 without `Accept: application/geo+json`, so every route fell back to straight-line estimates. Save is disabled while optimising; the E2E journey now checks the real distance and the saved trip. (`802fa3f`)

### Docs

- M1–M4 progress, decisions D-011…D-019, deploy guide and launch checklist. (`58ca58c`)

## 2026-09-27

### Added

- **App** — email/password, magic link + 6-digit code, Google and Apple sign-in (PKCE; native Apple on iOS); protected routes; 3-step onboarding; profile edit, language and units, account deletion; Explore with MapLibre map (web + native), city switcher, category filters and list view; attraction detail with image credit; pre-trip checklist screen; route tray (≤ 12 stops), optimisation, totals and save; My Trips list/detail/delete with Google/Apple Maps walking links. (`a548cea`)
- **Edge Functions** — `checklist` (visa, passport validity, power, Open-Meteo weather, FX, Canada advisories, practical info; each section degrades independently; cached) and `route-optimize` (OpenRouteService with nearest-neighbour + 2-opt fallback). Both require a signed-in user (D-015). (`9b5b1cd`)
- **Shared** — domain logic (best visa option, passport validity, plug/voltage compatibility, route fallback, map deep links), zod API schemas and EN/PT strings. (`0a59471`)
- **Database** — reference tables (countries, cities, attractions with PostGIS, visa rules, API cache) and user tables (profiles, nationalities, trips, trip stops) with RLS; RPCs `attractions_in_view`, `set_nationalities`, `save_trip`, `delete_account`; profile created on sign-up. (`f8c048d`)
