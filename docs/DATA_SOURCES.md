## Usage policies we follow

- **User-Agent:** every pipeline request sends `wayfarer-pipeline/<version> (<PIPELINE_CONTACT_EMAIL>)`.
- **Rate limits:** Wikidata SPARQL (≤ 1 concurrent query, back off on 429), Overpass (≤ 1 request at a time, honour `Retry-After`), Nominatim (≤ 1 request/second, never from the app), Wikimedia REST (≤ 100 req/s, we stay far below).
- **Caching:** raw responses cached under `data-pipeline/.cache/` during development (git-ignored).
- **No invented data:** missing fields stay `null` and the UI handles them.

## cities.yaml provenance

Retrieved 2026-09-26: Wikidata labels (en/pt), coordinates (P625) and country (P17 → P297); Nominatim search for bbox and OSM boundary relation. Istanbul uses a centre-based bbox because its OSM boundary is the whole province.

## Reference data provenance (retrieved 2026-09-27)

Generated by `data-pipeline` (see its README) into committed snapshots in `data-pipeline/data/` and seed SQL in `supabase/seed/`.

- **Countries** (`10_countries.sql`, 250 rows = 249 ISO 3166-1 codes + `XK` Kosovo): Wikidata SPARQL (P297 ISO code without end date, no P576; labels en/pt; P38→P498 currency; P2853 plug → IEC letter by QID; P2884 voltage + P2144 frequency; P1622 driving side; P474 calling code; P2852 emergency numbers with P366 use; P37→P218 languages), time zones from IANA `zone.tab`, EU/Schengen flags hardcoded (EU 27, Schengen 29). Curated corrections in `country_overrides.yaml` (each with a `source:`); launch destinations GB, FR, TR, IT, CZ, NL, ES, AT, PT and home countries BR, US are fully reviewed. Brazil is mixed 127/220 V — stored as 220 V.
- **Visa** (`30_visa.sql`, 39 402 rows): `passport-index-tidy-iso2.csv` at commit `a46dbc872002e01f6465a69071a7ed5b6dc8fc7b` (2025-01-12; the repository was archived in 2026, so data is not refreshed upstream). Numbers → `visa_free` with `max_stay_days`; passport and destination both in EU+EEA+CH → `freedom_of_movement`.
- **Attractions** (`40_attractions.sql`): Wikidata (CC0) + OpenStreetMap via Overpass (ODbL) + Wikipedia pageviews (Sep 2025 – Aug 2026) + Commons image metadata. Only freely licensed images are kept, each with author, licence and licence URL.
